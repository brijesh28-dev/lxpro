## 🌟 Features & Highlights

- **Interactive 3D Sartorial Carousel**: Smooth physical-spring card stack (`CardSwap`) with GPU hardware acceleration, drag-and-flick gestures, and zero-rerender mobile scaling.
- **Editorial Archival Showcase**: Full-bleed 3D arch carousel and responsive multi-column masonry grill with WhatsApp concierge inquiry.
- **8 Surat Flagships & Interactive Map**: Dynamic Leaflet map highlighting all 8 city ateliers with route directions, contact numbers, and store photography.
- **Dual Luxury Theme Mode**: Deep obsidian dark mode with marble gold gradients & warm ivory cream light mode, featuring circular view-transition reveals.
- **34-Year Heritage Winding Highway**: Interactive SVG automotive journey tracing milestones from 1992 to 2026.
- **Zero-Flicker Architecture**: Route-level code splitting, lazy-loaded components, and optimized asset pipelines.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Luxury Design System
- **Animations & Physics**: Motion (Framer Motion) + Custom Spring Ticker Engines
- **Mapping & Geospatial**: Leaflet + Custom SVG Map Markers
- **Icons**: Tabler Icons, Lucide Icons, Hugeicons
- **Typography**: Playfair Display (Serif) & Plus Jakarta Sans

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/brijesh28-dev/lxpro.git
cd lxpro
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
